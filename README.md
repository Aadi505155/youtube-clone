# YouTube Clone 📺

A responsive YouTube clone built with vanilla JavaScript that interacts directly with the **YouTube Data API v3** to fetch and display live trending videos and handle search queries.

## 🚀 Features

* **Live Trending Feed:** Fetches and populates popular videos dynamically using the YouTube Data API v3.
* **Search Functionality:** Allows users to query and look up specific videos or redirect to YouTube search results.
* **Category Filters:** Horizontal scrolling filter options layout for different topics (CSS, Web Development, Python, etc.).
* **Responsive Sidebar & Navbar:** Styled to closely mirror the core UI layout of modern YouTube.
* **External Playback:** Direct video links configured to open seamlessly on click.

## 🛠️ Built With

* **HTML5** – Structure and layout markup[cite: 1].
